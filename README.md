# NBCG International AD Siting and Community Protections

An information resource prepared for members of the National Biogas Concern Group.

It compares how anaerobic-digestion plants are sited, assessed and regulated in Ireland and several European and international jurisdictions, with a suggested planner checklist and points for the group to consider.

The page is a single index.html file with no external dependencies.

This is policy information, not legal advice.
