# NBCG International AD Siting and Community Protections

A self-contained, offline-capable information page prepared for the National Biogas Concern Group.

It compares how anaerobic-digestion plants are sited, assessed and regulated across several European and international jurisdictions, and sets out a proposed Irish framework and recommendations.

The page is a single `index.html` file with all styling and scripting inline and no external dependencies. It can be opened directly in any browser or served as a static site.

This is policy information, not legal advice.
